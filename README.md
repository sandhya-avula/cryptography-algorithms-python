# Cryptography Algorithms Implementation

## Project Overview
This project demonstrates cryptographic techniques using Python, including AES-256-GCM encryption and decryption, SHA-256 hashing, and detection of modified encrypted data.

## Technologies Used
- Python
- Google Colab
- Cryptography library
- hashlib

## Features
- AES-256-GCM encryption and decryption
- SHA-256 hash generation and comparison
- Detection of modified encrypted data
- Basic security testing

## How to Run
1. Open `Cryptography_Algorithms_Project.ipynb` in Google Colab.
2. Run the setup cell to install the required library.
3. Execute the notebook cells in order.
4. Review the encryption, hashing, and tampering test results.

## Security Notes
AES-GCM provides encryption and authentication when used correctly. Never reuse a nonce with the same key. SHA-256 is a one-way hash function, not encryption.

This project is intended for educational purposes.
